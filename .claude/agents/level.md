게시판 카페 웹에 회원 경험치 기반 레벨 시스템을 추가하고 싶습니다.

기능 요구사항:

1. 회원 레벨 시스템

- 모든 회원은 level과 exp 데이터를 가짐
- 회원가입 시 기본 레벨은 1
- 경험치는 작성 활동으로 증가

경험치 획득 규칙:

- 게시글 작성: +10 EXP
- 댓글 작성: +1 EXP
- 좋아요 획득: +2 EXP
- 하루 최대 획득 경험치 제한 100

2. 레벨 계산 시스템

- exp 누적량에 따라 자동으로 level 증가
- 예시:
  Lv1: 0 ~ 99 EXP
  Lv2: 100 ~ 299 EXP
  Lv3: 300 ~ 599 EXP

- 최대 5레벨까지 만들기
- 레벨업 시 자동 반영
- 현재 경험치 / 다음 레벨까지 필요한 경험치 표시

3. 데이터베이스 수정
   현재 User 모델에 다음 필드 추가:

User {
level Int @default(1)
exp Int @default(0)
}

필요하면 ActivityLog 같은 경험치 기록 테이블도 설계해주세요.

4. 게시글 작성 로직 수정
   사용자가 게시글 작성 완료하면:

- 게시글 저장
- 해당 회원 exp +10 증가
- 레벨 재계산
- 변경된 회원 정보 저장

5. 댓글 작성 로직 수정
   댓글 작성 완료하면:

- 댓글 저장
- 작성자 exp +1 증가
- 레벨 재계산

6. UI 표시
   회원 프로필 영역:

- 닉네임 옆에 Lv 표시
  예:
  [Lv.5] 홍길동

게시글 목록:
작성자 정보 영역에:
Lv.5 홍길동
작성글 20개

댓글:
작성자 닉네임 옆:
Lv.3 홍길동

7. 개발 방식
   현재 프로젝트 구조를 먼저 분석하고,
   기존 코드 스타일과 DB 구조를 유지하면서 구현해주세요.
   필요하다면 .md파일을 따르지 말고 최적화가 더 좋은쪽으로 구현해주세요.
   수정해야 하는 파일 목록과 변경 이유를 먼저 설명한 뒤 코드를 작성해주세요.
